# PackTrack — Moving Box Inventory Indexer

Never lose track of what's in which box again. PackTrack answers the universal
moving-day question: "where did I pack the HDMI cables?"

## What's inside
- `index.html` — the complete app. Single file, works offline.
  Open it in any modern browser (double-click, or File → Open). No install,
  no account, no internet needed — built for moving day, when the wifi is down.
- `gallery/` — 8 screenshots showing the app in action.

## Features
- Numbered boxes (starting at 101) assigned to rooms — 8 defaults, add your own
- Itemize contents per box; quick-add with the Enter key
- Instant search across every box with match highlighting
- Color tags, fragile flags, seal/unseal boxes
- Unpack mode: check off items at the new place with a progress bar
- Dashboard: totals, packed vs open, per-room counts
- Printable box labels — one per page with big box number, room, and FRAGILE banner
- JSON backup export/import, demo data to explore
- Dark mode (follows your system, remembers your choice)
- Everything stays in your browser — your data never leaves your device
