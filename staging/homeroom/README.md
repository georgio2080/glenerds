# HomeRoom — Homeschool Lesson Planner & Attendance Tracker

Weekly lesson plans, one-tap attendance, gradebook & reading log for homeschool families. 100% offline single-file web app.

## Features
- **Today** — today's lessons with done checkboxes, present count, school-day totals
- **Lessons** — per-student weekly planner (week navigation), subjects, notes, completion
- **Attendance** — one-tap present/absent per student per day, day navigation, year totals + attendance rate per student
- **Gradebook** — assignments with score/max → auto percentage + letter grade, per-subject averages with letter grades
- **Reading** — book log with author, pages, finish date, totals per student
- **Students** — multiple kids, grade levels, custom per-student subjects
- Dark mode (toggle, system preference on first load, persisted), localStorage persistence, JSON export/import, print summary, mobile responsive, zero external requests
